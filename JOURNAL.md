# Line-Follower Robot — Project Journal

## Project Journal

This journal records my progress while designing a line-following robot. It documents the work completed, what I learned, challenges, and next steps.

## Day 1 — Researching Designs

### What I did
- Explored different line-follower robot designs.
- Compared general chassis layouts and considered how the sensors, controller, motor driver, and motors might fit together.
- Researched the basic parts used in a line-following robot.

### What I learned
- A line follower uses sensors to detect a line on the surface.
- The controller uses sensor readings to adjust the motors and steer the robot.
- Chassis layout and component placement affect stability and assembly.

### Problems / Challenges
- I needed to compare different designs before deciding which layout would be practical to build.

### Day 1 Status
Initial design research completed.

## Day 2 — Finalising the Design

### What I did
- Finalised the line-follower robot as my project.
- Studied the basic working principle of the robot.
- Considered how the sensors, controller, motor driver, motors, and chassis work together.

### What I learned
- Sensors detect whether the robot is aligned with the line.
- The controller uses sensor readings to decide how the motors should move.
- The robot follows the path by adjusting its direction when the sensor readings change.

### Problems / Challenges
- The exact components and their final placement still need to be confirmed as the design develops.

### Day 2 Status
Project concept selected and basic working principle studied.

## Day 3 — Starting the Chassis Model in Onshape

### What I did
- Created an Onshape account.
- Started modelling the robot chassis.
- Considered where the main components should be positioned on the chassis.

### What I learned
- Onshape can be used to create and edit 3D part models.
- Planning component placement early can help make the design easier to assemble.
- Component dimensions and mounting points need to be considered while modelling the chassis.

### Problems / Challenges
- The chassis layout may need adjustments once the exact component dimensions are confirmed.

### Day 3 Status
Onshape account created; chassis modelling and component-placement planning started.

## Day 4 — Building the Components

### What I did
- Continued building/modeling the components for the robot.
- Worked on developing the mechanical layout around the chassis.
- Considered how the parts will fit together.

### What I learned
- Component models should match the real parts as closely as possible.
- Clearances and mounting positions matter when fitting components to a chassis.
- The design should be checked as a whole before moving to assembly.

### Problems / Challenges
- Component dimensions and fit still need to be checked against the final parts.

### Day 4 Status
Component modelling/building started.
